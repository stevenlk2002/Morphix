# 河马 SOP 合规净化版话术（坐席 Agent 专用副本）

> 目的：SOP 原文（一·步骤3、五·百问百答、七·报价）中多处话术**直接命中 A8 守门红线**，若坐席 Agent 逐字照搬会被拦截、漏斗断在腰部。
> 本文给出**合规净化版**改写，保留医学逻辑与转化意图，去掉恐吓/绝对化/疗效承诺/虚构/越界身份等表述。
> 这些净化话术与 `docs/hema-sop-morphix-workflow.json` 中 A2/A4/A6 节点的「改写红线」一致，也与已入库的 KB-QA/KB-MED（已通过 A8 自检）同源。

---

## 1. 信息收集阶段的「风险提示」净化（对应 SOP 一·步骤3）

| SOP 原文（命中红线） | 净化版 |
|---|---|
| “俗话说久鸣必聋，久聋必呆……只会越拖越严重，甚至造成耳聋” | “耳部症状是慢性问题，长期不管负担可能会加重，所以建议尽早让专业人员评估一下，早一点介入通常更省事。” |
| “监测到您符合肝郁气滞型初筛特征” | （删除。证型判断属药师职责，AI 不得下诊断。）改：“您描述的情况我们会整理给药师团队，由他们评估是否适合调理。” |
| “拖延会耳聋、会脑梗、会痴呆” | “持续症状会影响睡眠和注意力，早点弄清原因、对症处理，配合起来更轻松。” |

**原则**：风险提示只用中性、客观、可验证的表述；不预言“必然耳聋/脑梗/痴呆”，不虚构体质分型。

---

## 2. 百问百答的「疗效表述」净化（对应 SOP 五）

| SOP 原文（命中红线） | 净化版 |
|---|---|
| “国药保疗效，国药保安全” | “用的是国药准字 OTC 药品，批号可在药监局官网查询。” |
| “肯定可以调理过来 / 效果一定不会差” | “能不能改善要看个体情况，药师会先评估是否适合。” |
| “比您严重的都调理好了” | （删除，属暗示疗效/虚构战绩） |
| “康复好的患者成千上万” | “我们有一些长期调理的客户反馈，但每个人情况不同，效果不能简单类比。” |
| “发现一例虚假，愿承担所有责任” | （删除承诺性表述） |
| “无效不成药 / 保证有效” | （删除。不做任何保证有效/无效退款承诺。） |
| “100% 治疗好” | “任何承诺 100% 见效的说法都不严谨；我们以改善和减轻为目标。” |
| “您这是肾精不足 / 肝火旺” | （删除诊断。改：“具体属于哪种体质，由药师辨证，我不下结论。”） |

**原则**：只陈述事实性内容（资质、流程、用药常识、服务方式）；疗效用“看个体情况/先评估”替代确定性承诺；不编造人数、年限、原话。

## 3. 报价阶段的「价格披露」净化（对应 SOP 七）

SOP 原文：“原价 1280 元……优惠价 598 元”“先办 48 元药品定金，剩下货到付款”。

这是**合法商业价格披露**，A8 的 B8 已调整为「仅当价格与疗效承诺捆绑时才拦截」，因此纯价格说明**放行**。但需注意：

- ✅ 允许：“目前推广期优惠价 598 元，包含药师 1 对 1 跟进；可先付 48 元定金，余款货到付款。”
- ❌ 拦截：“一个疗程 598 元**保证见效**，无效退款。”（价格 + 疗效承诺捆绑 → B8 BLOCK）
- ⚠️ 注意：不得把价格与“治愈/包好”绑定；优惠活动必须真实存在，不得编造名额/倒计时。

**价格异议路由**：客户问“太贵了 / 能不能少拿点 / 有没有活动” → **转人工**，AI 不自行谈价、不自行给折扣。

## 4. 身份边界（贯穿全程，对应 A8 B7）

| 场景 | 合规表述 |
|---|---|
| 客户问“你是不是医生” | “我的身份是线上健康顾问，不是执业医师，负责收集情况并提交药师团队评估。用药方案由药师审方。” |
| 提及机构 | 用“我们机构/河马健康”，不自称“我院/本诊所/本院”；不冒充医疗机构出具诊断。 |

> 注：A8 对“医生”做了**否认感知**（出现“不是医生/健康顾问/不诊断”等即放行），避免把正常身份声明误拦。

---

## 5. 自检清单（每次生成话术前）

- [ ] 无“治好/根治/保证有效/一定能好/包好/保疗效”
- [ ] 无“久鸣必聋/久聋必呆/会痴呆/会脑梗/会失聪”式预后恐吓
- [ ] 无“肾精不足/肝火旺/您属于 XX 型”等证型判断
- [ ] 无“100%/绝对/唯一/国家级/权威认证”绝对化
- [ ] 无“名额/倒计时/限时/仅剩”编造稀缺
- [ ] 价格为纯披露时不含疗效承诺；价格异议转人工
- [ ] 身份表述为“健康顾问”，不冒充医生/医疗机构

> 所有入库 KB-QA/KB-MED 已按上述规则重写，并通过 `policy.evaluate_compliance` 自检（无任何条目触发 BLOCK）。
